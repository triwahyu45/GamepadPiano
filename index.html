Panduan Kontrol

  • Tuts Melodi (Piano Mode)D-Pad / Tombol A, B, X, Y

  • Atur Transpose (Turun/Naik)Tahan Share + ⬜ / 🔺
  • Reset Transpose (0)Tahan Share + ❌
  • Sustain LockTahan Share + L2/R2
  • Ganti Mode Piano/ChordTombol Options / Start
  • Tuts Putih (Do - Si)A, S, D, F, G, H, J, K, L, ;
  • Tuts Hitam (Accidentals)W, E, T, Y, U, O, P
  • Transpose Turun / Naik[ / ]
  • Ganti InstrumenAngka 1
  • Ganti Tangga Nada (Scale)Angka 2
  • Ganti Rentang OktafAngka 3
  • Toggle SustainAngka 4
  • Ganti Mode Arpeggio/StrumAngka 5
