Di Piano Mode, Anda dapat memicu harmoni akord indah dengan menekan beberapa tombol stik game secara bersamaan (kombinasi shortcut di Tangga Nada Mayor):

Akord Shortcut (Kombinasi) Jenis Suara
C Major D-Down + D-Left Simpel (E4 + G4)
C (Lengkap) D-Down + Triangle + R2 Voicing (C4 + C5 + E5)
D Major Cross + Circle Simpel (F4 + C5)
Dm (Lengkap) Cross + Square + Circle Full Chord (D4 + F4 + A4)
E Minor D-Left + D-Up Simpel (G4 + D5)
Em (Lengkap) D-Left + D-Up + R2 Voicing (E4 + B4 + E5)
F (Lengkap) Square + Circle + Triangle Full Chord (F4 + A4 + C5)
G Major D-Right + Cross Simpel (B4 + F4)
G (Lengkap) D-Right + D-Up + R1 Full Chord (G4 + B4 + D5)
A Minor Circle + Triangle Simpel (A4 + E5)
Am (Lengkap) Circle + Triangle + R2 Full Chord (A4 + C5 + E5)
B minor L1 + Cross Simpel (B3 + D4)
Bdim (Lengkap) D-Up + R1 + R2 Full Chord (B4 + D5 + F5)

*Info: D-Pad mekanik stik hanya mendeteksi maksimal 2 arah (diagonal). Oleh karena itu, akord C & Em versi lengkap dialihkan menggunakan kombinasi tombol aksi (kanan) & shoulder (R2) agar tetap dapat dimainkan dengan nyaman secara fisik.

Di Chord Mode, gunakan kedua stik analog gamepad Anda untuk memilih root nada dan tipe akord. Nada dasar diatur agar pas sebagai musik pengiring (inversi otomatis):

Kontrol Stik Arah Segmen Output
Analog Kiri (L-Stick) Arah Segmen (8 Segmen) C, D, E, F, G, A, B
L-Stick (Radius Jarak) Jarak Tengah vs Mentok Luar Oktaf Rendah vs Oktaf Tinggi
Analog Kanan (R-Stick) Arah Segmen (8 Segmen) maj, maj7, 7, sus4, m, m7...
Tombol R1 Modifier Kres (♯) Root + 0.5 Nada
Tombol L1 Modifier Mol (♭) Root - 0.5 Nada
