# Gamepad Piano

A creative web-based digital piano that allows you to play musical notes using a standard USB/Bluetooth **Gamepad Controller** via the Web Audio API.

🚀 **[Buka Live Gamepad Piano di sini!](https://triwahyu45.github.io/GamepadPiano/)**

---

## 🌟 Features

*   **Gamepad Control**: Bind controller buttons (D-pad, action keys, bumpers) to play musical scales.
*   **Polyphonic Audio**: Synthesis powered by the HTML5 Web Audio API (clean oscillator waves).
*   **Visual Keyboard**: Interactive keyboard on the screen that lights up when buttons are pressed on the gamepad.
*   **Zero Dependencies**: Written entirely in a single static `index.html` file using pure vanilla JavaScript.

---

## 🎮 How to Play

1. Connect your controller (Xbox/PlayStation/Nintendo/Generic USB) to your computer.
2. Open the **[Live Gamepad Piano](https://triwahyu45.github.io/GamepadPiano/)**.
3. Press any button on your controller to activate it.
4. Press buttons on the gamepad to trigger different piano notes!\n
